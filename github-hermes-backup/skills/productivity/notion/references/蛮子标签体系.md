## 资讯存储标准流程

**触发词**：「存到Notion / 存入Notion / 存知识库 / 这篇存一下」

1. **识别内容主题** → 对照上表匹配数据库
2. **打标签** → 按关键信息打标签（不打泛词），参考目标数据库现有条目的标签用法
3. **创建页面** → 写入标题 + 正文 blocks
4. **附微信原文链接** → 页面顶部加 callout（🔗 icon）+ 原始链接

## 标签打标原则

- **关键信息驱动**：不打「AI」「学习」等泛词，打文章核心概念（如「认知投降」「用进废退」「个体重构」）
- **参照现有条目**：先读目标数据库2~3条现有条目，理解蛮子惯用标签词汇后再打
- **标签来源**：蛮子提示语体系，不要自创标签
