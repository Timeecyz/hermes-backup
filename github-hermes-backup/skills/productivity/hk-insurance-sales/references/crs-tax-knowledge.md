## 一、CRS 共同申报准则（Common Reporting Standard）

### 现状概述
- **生效时间**: 2017年起，全球100+国家和地区陆续加入
- **中国角色**: 2018年9月起与香港、澳门、新加坡等启动首次信息交换
- **核心机制**: 金融机构（银行、保险、券商、信托）→ 当地税务机关 → 自动交换至他方税务局

### CRS 2.0 升级重点（OECD 2023+）
| 领域 | 变化 |
|------|------|
| 尽调范围 | 信托（discretionary trusts）、资管产品、加密资产逐步纳入 |
| 数据质量 | 新增多字段：账户余额、股息、利息、资本利得等 |
| 实际控制人 | 强化穿透核查（beneficial ownership） |
| 自愿披露 | 新增VDAP（Voluntary Disclosure Assurance Process），减少罚款 |
| 处罚力度 | 未合规账户处罚上限提高 |

### 香港保险在CRS下的处理
- **金融账户认定**: 储蓄型人寿保单、退保价值账户 → 均属于CRS下的「金融账户」
- **申报门槛**: 通常保单现金价值 > 一定金额触发申报（各国门槛不同）
- **高净值账户**: 保险公司需执行强化尽调（Enhanced Due Diligence）
- **交换信息内容**: 账户持有人身份、保单号、现金价值、退保价值、红利

### 大陆税务居民在CRS下的合规要点
| 场景 | 说明 |
|------|------|
| 香港账户信息交换 | 香港→中国国家税务总局，内容包括退保价值、分红 |
| 知道≠要交税 | 信息交换是数据报送，不是直接征税 |
| 合规资金来源 | 合法出境的企业跨境支付不受个人外汇5万限额约束 |
| 申报≠违规 | 海外金融账户主动申报（如外币账户申报）属合规，不是处罚 |

## 二、FATCA（外国账户税务合规法）

### 基本信息
- **颁布**: 2010年（美国）
- **生效**: 2014年7月
- **范围**: 全球外国金融机构（FFI）向IRS报告美国税务居民账户信息
- **不合规后果**: 该机构在美国的收入被扣缴30% withholding tax

### 谁是美国税务居民？
| 身份类型 | 触发条件 |
|---------|---------|
| 美国公民 | 无论居住地 |
| 绿卡持有者 | 持有美国永久居民卡 |
| 实际居留测试 | 过去3年累计≥183天在美国（需加权计算） |
| 出生地 | 在美国出生（即使从未来过美，可能仍是公民） |
| 父母身份 | 父母一方为美国公民/居民，新生儿可能自动获得公民身份 |

### 美籍宝宝（美籍儿童）的关键风险
- **教育路径**: 在美读书→可能触发实际居留测试→成为美国税务居民
- **FATCA申报义务**: 香港保险公司在销售前需确认投保人/受益人是否为US Person
- **W-9表格**: 美国税务居民需向保险公司提交W-9
- **分红/退保**: 美国税务居民的全球收入需在美国申报

### 香港保险公司的FATCA合规
- 必须在IRS注册为FFI（外国金融机构）
- 对US Person客户执行KYC（了解你的客户）程序
- 拒绝配合的账户可能被IRS处以30%预扣税

## 三、美国遗产税（Estate Tax）

### 2024年最新数据
| 项目 | 金额 |
|------|------|
| 免税额度（个人） | $12,920,000 |
| 免税额度（夫妻，跨栏） | $25,840,000 |
| 超额部分税率 | 最高40% |

### 香港保单与美国遗产税的关系
- **身故赔偿金** → 支付给美籍受益人 → 计入受益人的美国遗产总额
- 超过免税额部分 → 缴纳遗产税（最高40%）
- **关键时点**: 保单是否在遗产内，取决于受益人是否已是美国税务居民/公民

### 解决方案：不可撤销人寿保险信托（ILIT）
- 将保单转入ILIT（不可撤销信托）
- 信托作为受益人，身故赔偿金不计入个人遗产
- 彻底隔离美国遗产税
- **操作时点**: 越早设立越好（投保时最佳）

## 四、美国赠与税（Gift Tax）

### 基本规则
| 项目 | 说明 |
|------|------|
| 年度免税额（2024） | $17,000 / 年 / 受益人 |
| 美国税务居民→非美国税务居民 | 超过部分需申报，不一定有税 |
| 非美国税务居民→任何人 | 通常无美国赠与税 |
| 配偶之间 | 无限额（Marital Deduction） |

### 对香港保险的实际影响
- 父母（中国税务居民，非美国税务居民）→ 子女（美国公民）支付保费：
  - 需注意美国赠与税申报
  - 若子女为非美国税务居民身份的成年人，无美国赠与税
- 若子女已成为美国税务居民：超过$17,000/年的赠与需申报

## 五、资金出境合规路径

### 路径对比

| 路径 | 适用场景 | 合规要求 |
|------|---------|---------|
| 个人外汇（5万限额） | 小额、经常项目 | 仅限个人经常项下支出 |
| 企业跨境支付 | 大额、真实贸易/服务 | 合同+发票+ODI备案/跨境人民币 |
| ODI备案 | 超大额（数千万+） | 需商务部门、发改委、外汇局审批 |
| 地下钱庄（不合规） | — | **绝对不可用** |

### 推荐路径：企业通道
```
中国大陆公司账户（利润款）
    ↓ 贸易/服务合同 + 发票
    ↓ 合规跨境人民币结算 或 美元直接支付
香港公司账户（资质合规）
    ↓ 内部转账
香港私人账户 / 保险公司
```

### 合规要点
1. **合同**: 境内外公司之间有真实贸易或服务往来
2. **发票**: 形式发票+正式发票匹配
3. **外汇备案**: 涉及外汇局ODI备案的要提前完成
4. **税务合规**: 资金来源在中国大陆已完税（企业所得税等）

## 七、针对美籍宝宝家庭的保险结构建议

### 风险矩阵

| 风险 | 描述 | 应对 |
|------|------|------|
| 投保人变成美国税务居民 | 陪读超183天/年 | 提前规划居住时间，或放弃投保人身份 |
| 孩子成为美国税务居民 | 在美读书 | FATCA申报 + W-9提交保险公司 |
| 身故赔偿进入美国遗产 | 超$1292万免税额 | ILIT信托结构，设立时即规划 |
| 分红在美国申报 | 全球收入在美国纳税 | 建议咨询中美双国税务师 |
| CRS信息交换 | 中国税务居民在港资产被汇报 | 合规资金+主动申报 |

### 推荐结构
- **投保人**: 母亲（中国税务居民，非美国税务居民）
- **被保人**: 美籍女儿
- **受益人**: ILIT信托（身故赔偿）或指定非美籍亲属
- **资金路径**: 中国公户→香港公户→保费
- **服务包**: 税务评估 + 信托设立 + 资金通道 + 申报代办
