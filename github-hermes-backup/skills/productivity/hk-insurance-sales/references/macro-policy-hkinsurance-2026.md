# 宏观政策解读：国务院关于对外投资的规定（2026.7.1施行）

> 来源：微信公众号「杨祥 法学博士」+ 高朋律师事务所 + 中伦律师事务所 + 证券时报解读综合  
> 整理时间：2026.6.3 | 适用于香港保险销售场景

---

## 核心判断

《规定》并未否定合法境外投资，但它终结了以模糊权属、碎片化安排和侥幸心态为基础的跨境财富管理时代。

**对香港保险的直接意义**：保险作为「风险隔离/传承工具」的正向价值凸显，而非规避外汇管制的工具。回归保障本质，才是新规下的正确销售姿势。

---

## 一、为什么这部法规值得高度重视

| 要点 | 说明 |
|------|------|
| 法律位阶 | 行政法规（仅次于法律）> 部门规章，稳定性更高，处罚力度更大 |
| 居民个人纳入 | 首次将「居民个人」明确纳入法定投资者范围，不再处于法律灰色地带 |
| 覆盖范围 | 港澳台投资、境外金融投资、境外再投资全部涵盖 |
| 关键覆盖 | 香港保险/新加坡账户/BVI架构/境外证券 均已在覆盖范围内 |

---

## 二、对香港保险的具体影响（影响程度：中等偏低）

### 购汇合规
- 购买境外保险通常需要外汇出境，**不属于经常项目可自由购汇范围**
- 须走合规渠道，不能用个人5万美元额度购买投资型保险

### 保单质押融资
- 以香港保单为质押物在境外获得贷款，再用于投资——**此结构更易被穿透审查**
- 不建议推荐此类操作

### 大额保单实质认定
- 保费金额巨大、保单具有明显投资和财富转移功能的，可能被监管认定为「实质上的境外投资」而非单纯保险安排

### CRS信息交换
- 香港保单信息已通过CRS交换至中国税务机关，账户不再「看不见」
- 境外所得（股息/利息/基金分配）须在中国申报，20%比例税率

## 三、销售促进机会点

| 机会 | 说明 |
|------|------|
| 政策支持保险 | 第8条鼓励政策性保险机构为对外投资提供海外投资保险服务 |
| 传承工具价值凸显 | 保险的「确定性」「传承性」「保障本质」成为核心竞争力 |
| 合规体检需求增加 | 可为客户提供跨境资产配置合规性咨询服务（增值差异化） |
| 保障型产品优势 | 重疾/医疗/寿险在跨境配置中有不可替代优势 |

---

## 四、销售红线（抑制点）

**这些话不要说/不要做：**

| 禁用表述 | 原因 |
|---------|------|
| 「分散风险/转移资产」 | 触碰外汇管制红线 |
| 「规避外汇管制」 | 明确违法 |
| 「高回报/投资收益」 | 储蓄型/投连型保险面临更大审查压力 |
| 「保单质押融资再投资」 | 更易被穿透审查 |
| 「资金转出去」 | 触碰外汇管制红线 |

## 五、正确销售话术

### ✅ 正确的切入角度

| 角度 | 场景话术 |
|------|---------|
| 传承 | 「给孩子留一笔确定的钱，不受市场波动影响」 |
| 保障 | 「重疾/医疗险转移健康风险，不让家人为医疗费担忧」 |
| 风险隔离 | 「企业资产与家庭资产隔离，保护家庭财富不受企业经营风险牵连」 |
| 配置 | 「用香港保险做海外资产配置的一部分，对冲单一货币风险」 |

### ❌ 避免的表述

- 「把资金转出去」「分散单一货币风险」「规避外汇管制」
- 「高回报」「投资收益」「比存银行划算」
- 「买这个比买股票安全」等投资比较型表述

## 六、关键政策条款速查

| 条款 | 核心内容 |
|------|---------|
| 第5条 | 合法投资受支持，自主决策、自担风险、自负盈亏 |
| 第10-11条 | 分类分级监管（鼓励/限制/禁止清单） |
| 第12条 | 核准备案+信息报告+跨境资金登记 |
| 第13条 | 技术/数据/人员出境管控红线 |
| 第15条 | 安全审查覆盖资产转让和处分（不只初始投资） |
| 第27条 | 违规处罚：停止投资/限期处分资产/没收违法所得/罚款（投资额5‰-10‰） |
| 第33条 | 个人境外金融投资具体管理办法由国务院另行制定（尚未出台） |

## 七、政策背景（理解即可，无需向客户提及）

| 事件 | 含义 |
|------|------|
| 富途/老虎/长桥整治 | 个人投资者不能通过境外互联网券商绕开境内金融监管 |
| Manus事件 | 发改委穿透新加坡法人外壳，认定技术来自中国，触发安全审查 |
| 地缘政治逻辑 | 资本出海、技术出海、数据出海已合流——美国CFIUS/中国安全审查双向强化 |

监管关键词：**穿透、实质、安全、全链条**

## 八、已购保单客户行动建议

| 动作 | 说明 |
|------|------|
| 梳理保费来源 | 确保购汇记录可解释 |
| 保留凭证 | 购汇记录/完税证明/赠与协议/继承文件 |
| 评估税务申报 | 境外所得是否已完成中国税务申报 |
| 不要恐慌 | 合规持有的真实保障型保单并非打击对象 |

## 九、对客户说的话术模板

当客户问「新规对我有什么影响」时：

> 「这次政策不是要关上门，而是要规范市场。对你来说，关键是这笔钱从哪里来、用来做什么。只要来源清晰、保单功能是保障或传承，就不用担心。保险的价值不是'转出去'，而是'确定性'——无论市场怎么变，孩子教育金/养老钱是一定有的。」
