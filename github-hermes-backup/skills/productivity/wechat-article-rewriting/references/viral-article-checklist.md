# 公众号爆款文章自检清单
## "不躺平的钱" Claire 风格 · 写作规范

---

## 一、爆款标题公式（发布前必检）

### 合格标题必备要素

| 要素 | ✅ 有 | ❌ 无 |
|------|-----|------|
| 数字（具体/冲击感） | 45%、两年、3个月 | 模糊数字 |
| 情绪词（紧迫/好奇/恐惧） | 被端、暴跌、到头了 | 平铺直叙 |
| 受众标签（谁该看） | 跨境炒股的人、有港股账户的人 | 泛泛所有人 |
| 解决方案暗示 | 该走哪条路 | 只有问题没有路 |

### 禁止使用的标题类型

- ❌ 纯新闻标题（无观点）：「证监会发布公告」
- ❌ 悬念过度：「你绝对想不到…」「真相是…」
- ❌ 虚假恐吓：「你的钱完了！」
- ❌ 与内容不符的夸张：「富途一夜破产」

### 推荐标题结构（3选1）

```
公式A：【数字+冲击】富途暴跌30%，只剩两年窗口期
公式B：【问题+解决】跨境炒股的路被堵死？普通人还有一条合规出路
公式C：【身份+利益】有港美股账户的人注意：你的账户可能只剩两年可用
```

## 二、Claire 风格核心要素（写时对照）

### 账号人设
- **第一人称**："我是Claire"、"我帮很多家庭配置过…"
- **说人话**："说人话"、"把复杂讲简单"
- **专业但不高高在上**：不用"综上所述"，用"所以你可以这样理解"

### 文章结构模板

```
📌 账号名片（callout块，蓝底）
   └─ 专注领域 | 账号定位 | 更新频率

【PART 0】先说重点（结论先行，callout警报块）
   └─ 30字内说清：发生了什么事 + 普通人最该做什么

【PART 1】发生了什么（数据驱动）
   └─ 时间/数字/主体说清楚，不抒情

【PART 2】你的XXX会怎样（受众视角）
   └─ 用"你可以/你不能"而不是"用户可以"

【PART 3】为什么（追根溯源）
   └─ 打比方 + 类比，不纯讲政策

【PART 4】合规方案（自然带出产品）
   └─ 列出选项 → 分析 → 自然引出香港保险
   └─ 绝不强推，用"可能更适合普通人"表述

【PART 5】一张表/一张图说清楚
   └─ 对比类文章必须有可视化总结

【PART 6】为什么这个方案适合你
   └─ 逐条列优点，每条附场景说明

【PART 7】写在最后
   └─ 第一人称总结 → 互动引导 → 静态CTA
```

### 语气红线（绝对不能出现）

| ❌ 禁止 | 原因 |
|---------|------|
| "你必须"、"你一定要" | 命令感强，读者反感 |
| "毫无疑问"、"毋庸置疑" | 过度确定，丧失专业感 |
| "业内专家表示" | 空话，无来源 |
| 连续感叹号超过3个 | 情绪过度 |
| 纯政策文件摘要 | 无差异化，无可读性 |
| 纯产品硬推 | 用户感知硬广，举报率高 |

### 语气推荐（可以用）

| ✅ 推荐 | 场景 |
|--------|------|
| "说实话"、"说人话" | 表达真诚，拉近距离 |
| "你可以这样理解" | 降低认知门槛 |
| "很多人会问…" | 预设读者疑问，主动回应 |
| "这里有个关键点…" | 引导注意力 |
| "我的客户案例是…" | 具体场景，增加信任 |

## 三、原创度自检（发布前必过）

### 文字原创检测

| 检查项 | 方法 | 通过标准 |
|--------|------|---------|
| 与原文连续相同字数 | 复制原文 vs 改后文本，diff | 无超过15字连续重复 |
| 核心事实描述方式 | 数字/时间/主体是否换了一种说法 | 同一事实不同表述 |
| 逻辑结构 | 原文6个观点 → 改后是否重新排列组合 | 结构重组超过50% |
| 词汇替换 | 专业术语是否用同义词替换 | 超过30%词汇有变化 |

### 合规红线

| ⚠️ 注意 | 说明 |
|---------|------|
| 证监会/银保监数据引用 | 注明来源，仅引用事实不含政策解读 |
| 股价/跌幅数据 | 注明"盘前数据，截至XXX"，不做未来预测 |
| 产品对比 | 不指名道姓竞品缺点，只说"某渠道" |
| 投资建议表述 | 不用"建议买入"、"可以抄底"，用"可以考虑" |
| 收益数字 | 必须注明"演示收益率，非保证" |

## 四、爆款增强技巧（可选加分项）

### 开头钩子（30字内必须抓住）

```
❌ 平淡：今天来聊一聊跨境炒股的事情
✅ 冲击：富途暴跌30%——你的账户还能用多久？
✅ 数字：45%+30%+两年 = 跨境炒股的终结开始了
✅ 提问：你在富途/老虎有账户吗？现在有件事你必须知道
```

### 情绪节奏

```
第1段 → 紧迫感（发生了什么）
第2段 → 安全感（你的钱不会消失）
第3段 → 紧迫感（但只剩两年）
第4段 → 理性（为什么被罚）
第5段 → 希望感（合规的路还在）
第6段 → 获得感（香港保险这个方案适合你）
第7段 → 行动感（你应该怎么做）
```

### 互动引导句式

```
"你有没有遇到过类似的情况？欢迎留言告诉我。"
"如果你也在考虑香港保险，私信我【方案】，帮你看看是否适合。"
"关注我，下期讲讲香港保险怎么选。"
"评论区留下你的问题，我会挑选回答。"
```

### 爆款结尾公式

```
情绪总结（一句话概括全文核心）
    ↓
行动指引（读者现在可以做的一件事）
    ↓
静态CTA（关注账号，不失温度）
    ↓
原创声明（防抄袭，保护账号权重）
```

## 六、文章类型参考模板

### 热点解读型
```
开头：数据冲击（发生了什么，数字说话）
主体：4W1H（What/Why/How/Who + 你该怎么办）
结尾：延伸思考 + 行动建议
```

### 产品分析型
```
开头：痛点引入（大多数人的困惑）
主体：数据验证 + 场景说明 + 适合人群
结尾：自我评估（是否符合你的需求）
```

### 客户案例型（匿名）
```
开头：共情（你是不是也遇到过…）
主体：需求挖掘 → 方案设计 → 效果呈现
结尾：如果你有类似需求…
```

### 销售话术型
```
开头：实战场景（客户最常问的N个问题）
主体：每个问题的应答话术
结尾：延伸思考 + 互动
```

## 四件套输出（每次改写必须包含）

改写完成后，在 Notion 推送之外，**额外输出以下四件套**：

### 1. 爆款标题（3选1）
```
格式：数字 + 情绪词 + 受众标签 + 解决方案暗示
要求：3个标题供选择，各有侧重（冲击力型/问题型/身份型）
```

### 2. 公众号转发摘要（≤100字）
```
格式：≤100字，含核心信息 + 悬念钩子，引导点击阅读全文
要求：不能只是文章开头复制，要能独立成立、引发好奇
```

### 3. 朋友圈发文指引
```
格式：
- 第1句：hook（引发好奇/焦虑/共鸣）
- 第2-3句：核心信息（发生了什么+数字）
- 第3-4句：行动引导（评论区见/点击链接/私信）
配图建议：尺寸 1:1 或 3:4，建议配图描述
```

### 4. 配图文生图引导词（每个PART后配图）
```
格式：为文章每个主要PART提供配图建议
内容：
  a) 若原文有可参考图片 → 提取图片URL + 简短描述
  b) 若无 → 提供 Midjourney/SD 文生图 Prompt（英文，描述场景/风格/情绪）

配图 Prompt 规范：
- 英文
- 包含：主体 + 场景 + 风格 + 色调 + 情绪
- 结尾加 --ar 16:9 或 --ar 3:4（适配公众号配图比例）
- 示例：A Chinese professional woman in her 30s looking worried while checking her phone, sitting in a modern living room, documentary photography style, muted blue tones, sense of anxiety and uncertainty --ar 16:9
```
