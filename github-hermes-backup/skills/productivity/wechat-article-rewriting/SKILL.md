# 公众号爆款文章改写 — Claire 风格

## 核心规范

改写前必读：`references/viral-article-checklist.md`

## 改写流程（2026-06-02 更新）

1. 改写完成后，**直接飞书发给蛮子**，不走 wenyan-cli 草稿箱
2. 蛮子看完确认后，再更新草稿箱
3. 配套4件套（封面图Prompt+摘要+爆款标题+朋友圈转发内容）要一起给她

### Step 1: 读取素材
- 原文链接 → 用 curl 提取正文内容
- 确认文章类型（热点解读/产品分析/客户案例/话术模板）

### Step 2: 对照清单自检
- 标题：是否含数字 + 情绪词 + 受众标签
- 开头：30字内是否有冲击力
- Claire 人设：是否用第一人称
- 产品植入：是否自然（非硬推）
- 语气红线：是否有命令句/虚假夸大
- 原创度：是否超过15字连续重复

### Step 3: Claire 风格改写
按照以下结构重写：

```
📌 账号名片（callout，蓝底）
   └─ 专注香港保险｜全球资产配置｜财富传承

【PART 0】先说重点（callout警报块）
   └─ 30字内：发生了什么 + 读者最该做什么

【PART 1】发生了什么（数据驱动）

【PART 2】你的XXX会怎样（受众视角）

【PART 3】为什么（打比方，不纯讲政策）

【PART 4】合规方案（自然引出产品）

【PART 5】对比/一张表说清楚

【PART 6】为什么适合你

【PART 7】写在最后
   └─ 第一人称 → 互动引导 → 静态CTA → 原创声明
```

### Step 4: 推送 Notion
- Database: `34acd9aa-41cc-818f-aae0-c6ce9e77036f`
- 负责人: Claire
- 状态: 待发布
- 类型: 根据内容选择
- 标签: 港险/热点/产品分析/话术模板

### Step 5: 发布前自检（逐项打勾）
见 `viral-article-checklist.md` 第五节

## 禁止事项

- ❌ 与原文超过15字连续重复
- ❌ 命令句（"你必须…"）
- ❌ 虚假夸大（"暴跌"≠"破产"）
- ❌ 投资建议（"建议抄底"）
- ❌ 连续感叹号超过3个
- ❌ 无来源数据

## 输出格式

改写完成后输出：
1. Notion 草稿链接
2. 标题（符合爆款公式）
3. 改写要点说明（与原文的主要差异）
4. 自检结果（哪些清单项已通过）
