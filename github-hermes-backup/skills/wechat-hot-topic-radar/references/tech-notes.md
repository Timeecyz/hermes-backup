# 热点雷达技术笔记

## 2026-06-01 诊断报告

### 数据源实测结果（服务器环境）

| 数据源 | HTTP状态 | 实际返回 |
|--------|---------|---------|
| 百度热搜主榜 | 200 | ✅ 正常，30条 |
| 百度财经榜 `tab=finance` | 200 | ✅ 正常，30条高质量财经热点 |
| B站热门 API | 200 | ✅ 正常，20条 |
| 微博热搜页 | 200 | ⚠️ HTML正常但正则匹配失败，0条 |
| 今日头条API | 0 | ❌ 返回空 |
| 雪球首页 | 302 | ❌ 重定向到认证页 |
| 金色财经API | 0 | ❌ 返回空 |
| 百度新闻搜索 | 200 | ❌ CAPTCHA拦截，0条 |
| DuckDuckGo | 0 | ❌ 返回空 |

**根因**：服务器环境（IP）被主流中国平台识别为非常用客户端，部分境外服务直接拒绝。

### 百度财经榜的价值

```
私募业规模站上23万亿元
南向资金密集扫货港股科技股
睿健医药完成2.1亿C1轮融资
算力金属锡价格暴涨 半年飙涨40%
英国央行格林：稳定币需求或很快消退
```

这些是主榜完全没有的财经垂直内容，价值极高。

### 百度新闻CAPTCHA原因

百度新闻搜索检测User-Agent/Referer/Cookie，直接返回验证码页面。正则匹配0条。

### web_search工具为什么能用

内置web_search走的是Hermes Agent的搜索通道，不经过服务器环境的HTTP客户端，所以能绕过平台对服务器IP的限制。

### 有效替代方案

1. **百度财经榜** → `https://top.baidu.com/board?tab=finance`（已加入脚本）
2. **web_search主动搜索** → 对niche关键词（法律/税务/CRS）用web_search工具补充
3. **删除无效数据源** → 微博/头条/雪球/金色财经/DuckDuckGo全部移除

### 扩展关键词采集现状

法律/税务/CRS等词今天在热搜上根本没有，这是正常的——这些不是大众热点词。

当前脚本通过百度新闻搜索覆盖了"法律""税务""婚姻财产"三个词，各采到5条，但过滤后只有"鞠萍姐姐退休"命中"退休"。

**建议**：如果扩展词热点数量持续很少，考虑把cron里的hot_topic_radar.py升级为双模式——主脚本采集热搜 + 另一个用web_search做关键词主动搜索的模块。
