## 注意事项

1. **优先级逻辑**：「香港保险」优先于「保险」，「香港」单独出现时仅当无更高优先级词命中时才生效
2. **百度热搜局限性**：前30条通常为娱乐/游戏热点，保险相关命中率低是结构性现象，非故障。**必要时应以 `web_search` 关键词搜索作为补充**
3. **去重逻辑**：只写入Notion库里还不存在的热点标题（前15字匹配）
4. **热点时效**：热点内容通常2-3天内最有价值，及时跟进
5. **飞书推送**：必须使用 tenant_access_token + IM API 方式，webhook方式已失效（code:19001）

## 关键发现：数据源局限性与应对

### 百度热搜结构性问题

> **百度热搜偏娱乐/游戏**，保险/理财相关内容命中率低是**结构性现象**，非故障。

### 百度财经榜是意外宝藏

> `tab=finance` 里有私募23万亿、南向资金、算力金属锡、英国央行稳定币等财经垂直热点，**质量远高于主榜**，但需要单独请求。

### 主动搜索 vs 被动采集

> `web_search` 是效果最好的补充数据源——搜索结果天然聚集保险/财经话题，命中率远高于被动爬热搜。对于法律/税务/CRS等niche关键词，**必须用主动搜索**，被动爬永远采不到。

### 切入点建议（扩展版）

| 关键词 | 切入角度 |
|-------|---------|
| 法律 | 【法律视角】从「普通人必知的法律常识」切入，实用性强 |
| 税务 | 【税务规划】从「合理避税/合法节税」角度切入，高净值读者关心 |
| CRS | 【CRS/海外账户】从「全球税务透明化对内地居民的影响」切入 |
| 遗产税/房产税 | 【财富传承】从「税改趋势下的资产保全策略」切入 |
| 婚姻财产/家族信托 | 【财富传承】结合实际案例，讲「如何把财富安全留给下一代」 |
| 离岸资产/资产配置 | 【跨境资产配置】结合香港保险/海外账户，讲全球分散风险 |
| 基金/股票/国债 | 【投资理财】从「普通人该不该配置」角度切入 |
| 财务自由/FIRE | 【财务自由】从FIRE运动/被动收入切入，呼应搞钱群体 |
| 副业 | 【副业赚钱】从主业+副业双轨收入切入，结合销售经验 |
