# Weread API Setup — Known Issues & Workarounds

**Last verified: 2026-06-07**

---

## API Host Reachability

| Host | Used For | Reachable |
|------|----------|-----------|
| `i.weread.qq.com` | Agent API Gateway | ✅ Yes |
| `cdn.weread.qq.com` | Skill zip, static assets | ✅ Yes |
| `api.weread.qq.com` | Old Web API (requests-based scripts) | ❌ Not reachable |

**结论：** 用 `execute_code` + `urllib` 直接调 `i.weread.qq.com`，不要用 `requests` 调 `api.weread.qq.com`。

## Cookie Format: wrk- vs wr_sid

旧版 cookie 格式（`wr_sid=`）已不推荐使用。2025年后统一用 API Key 认证：

| Format | Auth Method | Works for API Key |
|--------|-------------|-------------------|
| `wrk-XXXXXXXX` | `Authorization: Bearer` | ✅ Yes |
| `wr_sid=XXXXXXXX` | Cookie header (old) | ⚠️ Deprecated |

**诊断 `totalBookCount=0`：**
API Key 有效（200 OK），但账号里没有任何带笔记的书。去 https://weread.qq.com/r/weread-skills 确认 key 绑定的是主账号。

## 合集书与多版本陷阱（高频踩坑）

**合集书注意：** 搜索「思考快与慢」返回的是合集 `bookId=3003944801`，该 ID 下无个人笔记数据。单独搜索子书名才能找到正确的有笔记的 bookId。

**同一书名多版本：** 微信读书同一本书常有多个版本（精装/平装/新版），只有读过的那个版本有数据。换版本后数据清零。

**已验证坑位：**
- 沉思录：第一个结果 bookId=3300191756 → 0笔记；正确版本 26797118 → 124条划线
- 贫穷的本质：3300187091（增订版）→ 0笔记；需换 bookId 重试

## 生产环境可靠性（2026-06-07 实测）

**连接中断：** 连续写入 40+ blocks 后 `i.weread.qq.com` 偶发 `Connection reset by peer`（errno 104）。
- 指数退避重试可恢复（`time.sleep(2 ** attempt)`，最多 3-4 次）
- 建议每个 batch 间隔 `time.sleep(0.5)`，每批 20 blocks
- 等待 5s 后重试对恢复性错误特别有效

## Feishu Calendar API: page_size Minimum

When querying Feishu Calendar events, `page_size` must be ≥ 50:
```
code 99992402 "field validation failed" — "the min value is 50"
```
Use `page_size=50` as the minimum, not 20.
