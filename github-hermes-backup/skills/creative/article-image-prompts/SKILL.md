## 配图位置规范

每篇文章标准配图：
1. **片头Banner** — 文章开头，奠定基调
2. **封面图** — 文章核心主题揭示
3. **章节配图** — 每个Part前一张（最多4张）
4. **片尾Banner** — 收尾，CTA或温情结尾

## 使用方式

当用户需要为文章生成配图时：
1. 根据文章主题选择适配色彩
2. 根据配图位置选择对应模板
3. 填充具体内容（人物、场景、数据点等）
4. 输出提示词供用户复制到AI生图工具

## 注意事项

- 色彩不超过5种，需和谐搭配
- 前景/中景/背景要有层次感
- 线条规格（0.8mm外轮廓/0.1mm内部）是固定参数，不删改
- 比例固定16:9（文章配图标准）
- 铜版颗粒质感是风格锚点，每条提示词必须包含
