# 微信公众号文章工作流（高能量女孩日记账号）

## 账号定位
- **账号名：** 高能量女孩日记
- **内容方向：** 精力管理、AI工具实操、运动读书、日常生活
- **调性：** 接地气、有洞察、不鸡汤，女生成长/赚钱心智，"想清楚、行动利落、遇事不乱"

## 审稿流程

### 步骤1：分析草稿 → 输出修改建议

收到蛮子草稿后，分析并输出格式：

```
【问题N】位置 + 问题描述
→ 建议改成：替换后的文本
```

最多7处，说清楚"在哪"+"改成什么"，蛮子直接复制粘贴。不做全文重写。

### 常见修改类型

| 类型 | 处理方式 |
|------|---------|
| 链接格式错误 | 指出错误，给出正确URL |
| 逻辑跳跃/步骤残缺 | 补充过渡句 |
| 语气过激 | 加括号去敏 |
| 大小写/错别字 | 直接给正确文本 |
| 只引流一个账号 | 必须同时引流两个 |

## 标题选择原则

- **避免：** 纯噱头型（"89块/月，我把自己活成了一家AI公司"）——太爆款，跟生活管理账号调性不符
- **推荐：** 痛点驱动型，读起来像真实复盘
- **可用示例：** `用了2个月OpenClaw，我终于从自我管理中彻底解放了`
- **字数：** 20字以内，强钩子前置

## 生成可粘贴版本

确认修改后，输出完整微信文本，保留：
- 标题（独立一行或加粗）
- 分段（空行分隔）
- 列表（• 或 01/02 编号）
- 引用（加 > 或加粗）
- 分隔线（---）

## 写入Notion

### 正确顺序（重要）

Notion API 网络不稳定，`Connection reset by peer` 可能导致部分写入失败。

1. **内容先写入本地 .md 文件** — `~/.hermes/cache/documents/文章标题.md`（永久保存）
2. **再尝试写入 Notion**
3. **写入失败时** → 告知蛮子文件位置，让她直接复制粘贴到公众号编辑器

### 技术要求

- Python `urllib` + SSL context（不用 curl）
- 每批 ≤5 blocks，batch 间 sleep 1s
- 连接错误时重试3次，每次间隔2s
- Markdown 内容用 `callout` block 类型，emoji 用 📝

## 生成摘要和朋友圈文案

**公众号摘要（100-120字）：**
- 第一句：痛点或Hook
- 中间：核心内容一句话
- 结尾：这篇文章适合谁

**朋友圈转发文案（50-80字）：**
- 第一人称，像真实分享
- 带数字（89块/月、2个月）
- 末尾加"需要自取"
