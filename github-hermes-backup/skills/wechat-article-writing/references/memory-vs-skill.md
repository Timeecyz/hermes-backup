# 蛮子内容存储决策指南

> 来源：蛮子对话 2026-06-03 | 蛮子自述原则

---

## 决策框架：存哪里？

### 存 memory 的（3类）
1. **蛮子的个人偏好/习惯/怪癖** — 她说一遍，我不想再问第二遍的
2. **环境事实** — API地址、文件路径、系统限制
3. **跨会话悬而未决的任务状态** — pending 项需要续接的

### 不存 memory，封装成 skill 的（3类）
1. **流程性知识** — 怎么做一件事的步骤（封面规范、发布流程）
2. **工具性知识** — 某个skill怎么用、什么场景选什么
3. **可复用的方法论** — 写文章的格式、销售技能、选题策略

---

## 判断标准（一句话）

> 能「教给下一个新会话照着做」的 → **skill**
> 只对「理解蛮子这个人」有用的 → **memory**

---

## 示例

| 内容 | 存哪里 | 原因 |
|------|--------|------|
| 封面默认用 Midnight Ink 深色暖金 | wechat-article-writing skill | 操作参数，可复用 |
| 蛮子喜欢直接给反馈不兜圈子 | memory | 理解蛮子这个人的风格 |
| 2W2H 费曼学习法考核流程 | 独立skill | 方法论，可复用 |
| Notion API 的 UUID 连字符坑 | memory | 环境事实，临时 |
| 蛮子文章发飞书确认不推草稿箱 | wechat-article-writing skill | 操作流程 |

---

## 坑：容易存错的地方

- ❌ 把「skill 的操作参数」存进 memory → 下个会话还是不知道怎么操作
- ❌ 把「蛮子的个人偏好」封装成 skill → skill 变得臃肿且不可移植
- ✅ 工具偏好 → skill | 人的特点 → memory
