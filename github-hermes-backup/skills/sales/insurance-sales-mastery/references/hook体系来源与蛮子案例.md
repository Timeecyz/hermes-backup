# 钩子体系来源：天哥《聪明的销售，讲话都带钩子》

> 原文：https://mp.weixin.qq.com/s/iykx3GrDUjsphKVRzGarbA  
> 天哥，北大毕业，10+年销冠

## 原文核心观点

1. 钩子 = 让客户**忍不住想听下去**的那句话/问题/信息点
2. 底层逻辑：不是"我想卖"，而是"你能得到"——回答"这跟我有什么关系"
3. 四种通用钩子：数据 / 对标 / 问题 / 稀缺
4. 钩子是开胃菜，接住才是关键——产品讲清楚、方案拿得出、数据有证据

## 蛮子整合版 vs 原文差异

| 维度 | 原文 | 蛮子版 |
|------|------|------|
| 场景 | 通用B2B销售 | 港险/保险销售 |
| 钩子数量 | 4个通用型 | 4个通用 + 5个保险专属 |
| 新增钩子 | — | 担忧脱钩、故事钩子、身份认同、认知差、关系钩子 |
| 接住机制 | 泛泛提"专业能力" | 具体化为"三件套"（方案对比/需求三层/数据支撑） |
| 检查清单 | 无 | 有（5条，联系客户前必过） |
