# HK保险计划书解析技能 v2

## 基本信息
- **技能名**：HK保险计划书解析
- **版本**：v2（新增演示提取模块）
- **触发词**：分析PDF / 提取保单 / 读计划书 / 香港保险 / 保单分析 / 计划书解读 / 帮我提取这张保单
- **输入**：PDF附件（香港保险建议书）
- **输出**：结构化数字 + 标准化表格 + 演示提取对比

---

## 核心方法论

### HK保险PDF标准结构（通用）

```
第1节：建议书摘要 → 基础信息
第2节：保障摘要 → 保费/年限/保额
第3节：说明摘要 → 退保发还金额 + 身故赔偿（最重要）
第4节：悲观/乐观情景 → 非保证金额范围
第5+节：演示提取（Illustrated Withdrawal）→ 客户提取方案 ⭐重要
```

### ⚠️ 关键规则：不用页码定位，用关键词定位

每家公司的页码不同，必须用关键词找到正确章节：

| 公司 | 章节关键词（中文） | 章节关键词（英文参考） |
|------|------------------|----------------------|
| 永明 | 附加說明摘要（提取方式） | Illustration - Withdrawal |
| 宏利 | 款項提取說明 | Illustrated Withdrawal |
| 友邦 | （待确认，搜索"提取"相关） | Illustrated Withdrawal |

**搜索路径：**
1. 搜索 `"提取"` 或 `"现金提取"` → 找演示提取章节
2. 搜索 `"保單年度"` + `"受保人年齡"` → 找年度/年龄对应表
3. 搜索 `"累計"` + `"退保價值"` → 找提取后的账户剩余
4. 搜索 `"款項提取"` → 宏利专属
5. 搜索 `"无忧选"` 或 `"無憂選"` → 永明无忧选提取说明

## 操作步骤

1. **接收PDF** → 用 `pdfminer.high_level.extract_text` 读取全文
2. **搜基础信息** → 找第1-2节，提取产品名/保费/投保人/受保人
3. **搜退保发还** → 找第3节，搜索关键词 `"退保"` 或 `"退保價值"`
4. **搜演示提取** → 搜索关键词 `"提取"` / `"款項提取"` / `"附加說明摘要"`
5. **解析数字表** → 提取关键年份数据（注意：PDF解析数字可能有误差）
6. **输出结构化内容** → 按6个模块顺序输出
7. **演示提取另存Excel** → 必须单独建三险对比Excel，格式如下

## 字段提取规则

### 退保发还总额 = 保证现金价值(A) + 复归红利(B) + 终期红利(C)

### 年龄换算
- 宏利：受保人7岁（VIP小弟弟），2026年=第1年

## 注意事项

1. **⚠️ 不用页码定位** — 每家页码不同，必须用关键词搜索
2. **⚠️ 演示提取必须单独建Excel** — 这是客户最关心的"能领多少钱"，必须可视化
3. **数字核实** — PDF文字提取有误差，重点核对第5/15/30/65岁四个节点
4. **三险对比时年份对齐** — 不同受保人起始年龄不同，需换算到同一年龄对比
5. **悲观/乐观情景** — 宏利有悲观情景提取上限说明（$124,860），需特别标注
