# dreamina（即梦）CLI 配图生成指南

**更新：2026-05-28**

---

## 安装

```bash
curl -s https://jimeng.jianying.com/cli | bash
# 安装路径：~/.local/bin/dreamina
```

---

## 登录流程（OAuth Device Flow）

```bash
dreamina login
```

输出示例：
```
请使用浏览器完成 OAuth Device Flow 登录。
verification_uri: https://jimeng.jianying.com/ai-tool/cli-auth?...
user_code: 28e23ad4d33b39145d6cf650a45037b8
device_code: 8ee622493d8724a9a7ccc337dbb8ad2d
poll_interval: 1s
expires_at: 2026-05-28T14:42:11+08:00
```

**用户操作步骤：**
1. 用手机/电脑浏览器打开 `verification_uri` 链接
2. 输入显示的 `user_code`
3. 确认授权

登录成功后可立即提交任务。

---

## 生成图片（text2image）

```bash
dreamina text2image --prompt="<英文prompt>" --ratio=16:9 --resolution_type=2k
```

**常用参数：**
- `--ratio`：`1:1`（正方）、`16:9`（横版）、`9:16`（竖版）
- `--resolution_type`：`1k`、`2k`（推荐2k）
- `--prompt`：英文描述，中文内容在 prompt 中效果差

**异步任务：** 提交后返回 `submit_id`，用 `dreamina query_result --submit_id=<id>` 轮询。

---

## 轮询结果

```bash
dreamina query_result --submit_id=<submit_id>
```

`gen_status` 说明：
- `querying`：生成中，继续轮询
- `success`：成功，返回图片 URL
- `fail`：失败，查看 `fail_reason`

## 蛮子配图风格提示词模板

### 片头Banner
```
16:9横版，手绘插画风格，米色纸质纹理背景。
画面中央：一个穿着简约现代的女生站在岔路口，左边一扇深色大门缓缓关闭门上画着❌，右边一条明亮小路延伸向远方有小光点✨，女生回头看了看来时的门，表情平静略带释然，迈步走向右边小路。
```
