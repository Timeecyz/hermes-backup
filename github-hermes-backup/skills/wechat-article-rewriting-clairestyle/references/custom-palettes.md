## 墨绿暖调系 · Sage Green Warm（本次验证）

用于「高能量女孩日记」公众号，适合高能量女孩/自我成长/深度工作类内容。

```css
:root {
  --paper: #f3f4ef;      /* 淡米绿底 */
  --paper-2: #e2e8d8;    /* 浅墨绿 */
  --ink: #1c2e1c;        /* 深墨绿 */
  --muted: #5d6b5a;      /* 灰墨绿 */
  --line: rgba(28,46,28,.20);
  --accent: #4a6741;     /* 鼠尾草绿/橄榄绿 */
  --accent-soft: #d4dfcc;
}
```

配图尺寸规范：
- 小红书封面/内文：1080×1440（3:4）
- 微信主封面：2100×900（21:9）或 1920×1080（16:9）
- 微信方封面：1080×1080（1:1）

配图结构（高能量女孩日记标准4张）：
