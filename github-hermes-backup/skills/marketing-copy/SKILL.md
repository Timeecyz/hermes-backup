## 触发条件
提到营销文案、朋友圈文案、社群文案、短视频脚本、宣传内容，且关联内地保险、香港保险、财富管理、信托领域

## 执行步骤
1. 确认营销场景（前端宣传/老客维系/转介绍）与发布渠道（朋友圈/社群/短视频）
2. 结合对应领域特点（如香港保险突出分红，信托突出财富传承），提炼核心价值点
3. 结合客户痛点，生成短平快、有吸引力的文案，符合合规要求，不夸大
4. 标注文案适配场景与渠道，可直接复制使用
5. 将文案同步至飞书多维表格文案库，便于后续复用

## 补充要求
- 朋友圈文案：100字内，突出重点，带行动指引（如"私信咨询""预约详解"）
- 社群文案：150字内，有互动性，贴合社群氛围，不生硬刷屏
- 短视频脚本：分镜头/旁白，简洁明了，突出核心价值，时长适配短视频平台
