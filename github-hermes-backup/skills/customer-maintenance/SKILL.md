## 触发条件
提到老客维系、二次开发、转介绍、客户裂变，且关联目标领域

## 执行步骤
1. 确认场景（老客维系/二次开发/转介绍），结合客户类型（老客/高净值老客）
2. 生成针对性方案：老客维系（节奏、内容、话术）、二次开发（需求挖掘、产品匹配）、转介绍（话术、激励建议）
3. 方案符合合规要求，转介绍激励建议合理，不违规
4. 明确时间节点、执行动作，同步至飞书日历设置提醒
5. 将方案、话术同步至飞书多维表格，便于执行与复盘

## 补充要求
- 老客维系话术有温度，不生硬推销，侧重情感连接与价值传递
- 二次开发贴合老客潜在需求，不盲目推荐产品
- 转介绍话术委婉，明确转介绍流程与激励，不频繁打扰客户
