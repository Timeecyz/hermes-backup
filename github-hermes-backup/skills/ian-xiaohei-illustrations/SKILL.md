# Ian 小黑怪诞正文配图

## 核心定位

为中文文章设计和生成 **16:9 横版正文配图**。目标不是做商业插画、PPT 信息图或可爱卡通，而是把文章里的关键判断、流程、结构、状态或隐喻，变成一张清爽、怪诞、有创意、可读但不说明书的手绘解释图。

默认视觉 IP 是"小黑"：黑色实心、白点眼、细腿、空表情，认真做一件荒诞但成立的事。小黑必须参与画面的核心动作，不能只是站在旁边当装饰。

## 视觉风格

- **纯白背景**：不要米色、暖灰、纸张纹理、渐变、阴影、噪点
- **黑色手绘线稿**：细线、轻微抖动、不机械、不矢量
- **大量留白**：主体占画面约 40%-60%
- **少量中文手写批注**：最多 5-8 处，每处 2-8 字
- **颜色用法**：
  - 黑色：主体线稿、角色、框线、主要文字
  - 红色：重点批注、问题、关键提醒、结果
  - 橙色：主流程、路径、箭头、自动化流向
  - 蓝色：补充说明、脑内状态、AI提示（克制，宁可少不要多）

## 小黑 IP

- 黑色实心小怪物，白色圆点眼睛，细腿
- 表情空、呆、冷静、认真，很认真但做的事有点荒诞
- 像低调的系统操作员，冷幽默，不卖萌
- **必须承担核心动作**：搬运、拉线、判断、操作杆、盖章、分拣等
- 如果去掉小黑画面仍然完全成立，说明小黑太装饰了

## 绝对禁止

- 商业插画、PPT 信息图、可爱卡通、儿童插画
- 复杂架构图、真实 UI 截图、科技感界面
- 左上角写"Workflow / 系统架构图 / 常见坑"等类型标题
- 背景有纸纹、阴影、渐变、米色、噪点
- 复刻旧案例构图（每次要从当前文章重新发明隐喻）

## 工作流

### Step 1：分析正文 → 输出 shot list

先读正文内容，提炼"认知锚点"（核心判断、断点、分流、前后对比等），然后：

**先出配图策略**（不要先生成）：
每张图写清楚：
- 放在哪个段落后
- 图的主题
- 核心意思
- 结构类型
- 小黑在做什么
- 建议中文标注词

默认 4-8 张，短文 1-3 张。

### Step 2：逐张生成

用户确认 shot list 后，每张单独调用 `image_gen` 生成。
提示词必须包含：
- 16:9 横版中文正文配图
- 纯白背景
- 黑色手绘线稿，轻微抖动
- 少量红色/橙色/蓝色中文手写批注
- 大量留白
- 小黑作为核心动作主体
- 禁止 PPT、商业插画、幼稚可爱、复杂架构、左上角类型标题

### Step 3：QA 检查

生成后逐张检查 `references/qa-checklist.md`，如有失败信号立即重生成。

### Step 4：交付存档

保存到 `assets/<article-slug>-illustrations/`，按 `01-topic.png` 命名。

## QA 必过项

- [ ] 16:9 横版
- [ ] 干净白底
- [ ] 有小黑
- [ ] 小黑承担核心动作
- [ ] 没有复刻旧案例构图
- [ ] 画面怪诞但能看懂
- [ ] 主体不超过画面约 60%
- [ ] 中文标注少、短、能读
- [ ] 颜色克制（橙仅路径、红仅重点、蓝仅补充）
