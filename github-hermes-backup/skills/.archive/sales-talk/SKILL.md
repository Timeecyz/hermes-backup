## 触发条件
提到话术、客户沟通、异议处理、初次接触、促成成交、转介绍，且关联目标领域

## 执行步骤
1. 确认沟通场景（初次接触/需求挖掘/异议处理/成交促成/转介绍）与客户情绪（感兴趣/犹豫/顾虑/拒绝）
2. 结合对应领域特点，生成贴合客户情绪的话术，不生硬、不误导，符合合规要求
3. 话术分两种形式：独白式（主动沟通）、问答式（应对客户疑问），可直接复制使用
4. 针对客户常见异议（价格高、顾虑风险、犹豫不定），给出针对性应对话术
5. 将话术同步至飞书多维表格话术库，按场景分类存储，便于检索

## 补充要求
- 话术贴合客户类型（高净值客户：侧重专业、稳健；普通客户：侧重实用、便捷）
- 异议处理话术：先共情，再解答，不否定客户，传递核心价值
- 转介绍话术：语气委婉，突出互利，给出明确的转介绍指引
