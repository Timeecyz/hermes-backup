## 触发条件
提到销售环节、营销流程、跟进计划，需要拆解环节、明确动作

## 执行步骤
1. 确认营销环节（前端宣传/线索获取/客户跟进/成交/售后/老客维系/转介绍）
2. 用结构化清单拆解该环节：目标→核心动作→使用工具→时间节点→注意事项
3. 结合4大专业领域特点，优化环节动作（如香港保险跟进需增加汇率风险提示）
4. 输出可直接落地的执行计划，明确每个动作的目的与要求
5. 将环节拆解方案与执行计划同步至飞书多维表格，便于后续执行与复盘

## 补充要求
- 环节拆解清晰，层级分明，每个动作有明确目标，不冗余
- 结合飞书工具，明确每个动作对应的表格录入、日历提醒操作
- 贴合营销全流程闭环，确保每个环节衔接顺畅，不遗漏
