# 白玛师姐 · 面谈场景剧本

> 生成时间：2026-05-23  
> 客户画像：专业投资者 · 美籍双娃妈妈 · 800万预算 · 主攻香港储蓄险（隽富/中国人寿海外）  
> 面谈场景：桐梓林银子咖啡 Brunch

---

## 场景一：「我不需要低收益产品」

**触发：** 师姐觉得低收益产品在拖累她的投资回报  
**框架：** 去阻抗 + 身份锚点

```
师姐，我先说个数字，你听听对不对。

你现在的股票账户，收益是账面子还是已经落袋的？

我知道这个问题有点扎心，但作为两个孩子的妈妈，你肯定比谁都清楚——
股市里赚的钱，只要还在账户里，就不是真正属于你的。

你不是在选择"炒股还是保险"，
你是在给孩子建立一个"不管股市怎样，18岁一定有钱上大学"的账户。

这两个账户，各管各的事，不打架。
```

---

## 场景二：「800万要投资，不是存钱」

**触发：** 800万是大钱，要生钱，不是存起来  
**框架：** 竞品对比 + 愿景牵引

```
师姐，800万确实不是小钱。

但我想问你一个问题——这800万里，有多少是"不管发生什么，孩子18岁一定要用的钱"？

如果有，那这部分钱，放股市里和放保险里，哪个更能确保它到时候一定在？

教育金不是赌输赢，教育金是"不管发生什么，必须有"。

我见过太多投资人，最后发现孩子出国那一刻，股市刚好在低位。
那个痛，不是钱能衡量的。
```

---

## 场景三：「隽富的收益到底有多少？」

**触发：** 师姐要数据，不能接受模糊承诺  
**框架：** 权威 + 数字说话

```
师姐，这个问题问得好。

隽富（宏利GN16）这类型产品，核心逻辑不是"比股市收益高"，
而是"在安全的前提下，让时间成为你的朋友"。

给你几个参考数字：
· 5年缴，到第15年 IRR 约3.5-4%
· 第20年 IRR 约5-5.5%
· 美元计价，天然对冲汇率波动

我不需要你相信这个数字。
你需要的话，我可以拿计划书给你看，每年的现金价值都写在里面。
```

## 场景四：「我两个美国籍宝宝，有没有税务问题？」

**触发：** 美籍宝宝妈妈，美国税务身份是真实顾虑  
**框架：** 专业背书 + 情感锚点

```
师姐，这个你问对了。

美籍宝宝持有香港储蓄险，有一些技术细节需要处理。
但我要先问你一个问题——

你让孩子持有这个保单，是为了让他们18岁有教育金，
还是现在就让他们操作？

如果是你作为投保人、孩子作为受保人，
这个结构在税务上的处理是：你自己是税务居民，
保单的受益安排本身，是给孩子的一个确定性传承。

具体到你的情况，建议你带税务顾问一起聊。
我不是税务专家，但我知道这个流程怎么走。
```

## 场景五：「我什么时候投保最划算？」

**触发：** 想等一个"更好的时机"  
**框架：** 紧迫感 + 孩子年龄锚点

```
师姐，11岁投保，不晚。
但再晚两年，就真的晚了两年。

投保这件事，时间成本是最大的成本。

你女儿11岁，如果现在投保，到她18岁，有7年复利。
如果等到13岁，只有5年复利。
那两年的差距，是属于她的，不是属于别人的。

而且你儿子才1岁半，他现在投保，到他大学毕业或者创业，
有几十年的时间让复利滚动。

时间是你最大的盟友，不是敌人。
现在投保，是用现在的钱，买未来的时间。
```

## 场景六：「我不想从股市取钱」

**触发：** 股市资金不能动，这是她的底线  
**框架：** 去阻抗（核心场景）

```
师姐，这个你放心。

投保这个计划，不需要你从股市里取一分钱。
是从你每个月的收入里，分一小部分出来。

你一个月收入多少，我不需要知道。
但你可以算一件事——

每月省下5000块，一年6万，5年30万。
这30万，跟你的股市账户没有任何关系。
它是独立的，是孩子18岁那年，一定会在那里的钱。

你的股市继续炒，收益继续搏。
这个账户，是你的"不败底仓"——不管股市怎样，你不会输掉孩子的教育金。
```

## 场景七：「教育金和传承，我到底该怎么分配？」

**触发：** 800万预算，两个孩子，需求复杂，不知道怎么分配  
**框架：** 分账户管理

```
师姐，800万分成两个思路，你就清楚了：

【账户一：教育金——两个孩子各有专属】
· 女儿11岁：建议用较短周期，比如5-8年，把她18岁前的规划锁定
· 儿子1.5岁：时间更长，可以用更长的复利周期，给他留更足的空间
· 两个账户分开，互不影响

【账户二：传承——给你自己的一个长期规划】
· 如果你有传承需求，香港储蓄险的身故赔偿可以指定给受益人
· 不需要复杂的法律程序，比房产、遗嘱更简单

你更想先聊哪个？
```

## 场景八：「我老公不知道，我自己做主行吗？」

**触发：** 家庭财务决策，她想先自己搞清楚再和老公说  
**框架：** 喜好 + 身份锚点

```
师姐，当然可以。

但我想问你一个问题，你再决定要不要带他——

如果万一发生意外或者大病，你家能拿出多少钱来？

这个问题，你可以回家问他，看看他会怎么想。
如果他的答案和你一样清晰，那我们可以一起聊。

如果他的答案让你有点担心，那这个对话就更有必要了。

我不是来让你瞒着老公的，我是来帮你两口子一起给孩子建一个保障的。
```

## 场景九：「为什么选中国人寿海外？」

**触发：** 大公司 vs 其他香港保险公司，她要理由  
**框架：** 权威 + 合规背书

```
师姐，你选得很准。

中国人寿海外是目前香港市场上规模最大的中资保险公司之一，
偿付能力充足，合规监管和国际接轨。

你选储蓄险，核心看三点：
第一，公司实力——会不会有兑付风险？
第二，产品结构——现金价值写进计划书，不是预期数字
第三，服务体验——有没有人持续服务你，而不是卖完就走

中国人寿海外，这三点都满足。
```

## 场景十：「我现在还犹豫，怎么回事？」

**触发：** 有顾虑但说不清是什么，可能是身份认同问题  
**框架：** 承诺与一致 + 深层动机挖掘

```
师姐，犹豫不是坏事。
我想帮你把这个犹豫说出来。

你是不是在想——"我是个专业投资人，做保险会不会影响我的形象？"

我完全理解。

但你有没有想过——
你的专业，体现在你知道什么时候该进攻，什么时候该守住底线。

真正厉害的投资人，不是满仓干到底，
而是知道哪部分钱是"不管怎样都不能动"的钱。

做这个决定，不是你从投资圈转行了，
是你在用自己的专业，给孩子的未来上一把锁。
```
