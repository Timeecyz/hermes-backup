# 顶尖销售框架话术库

## 使用场景
- 客户沟通前：准备当次对话的核心框架和话术锚点
- 沟通中：调取对应框架，即时组织话术
- 每次沟通后：复盘用的是哪个框架，效果如何

---

## 框架一：事件营销（危机 → 替代方案）

**触发情境：** 客户持有某投资产品遇到监管危机（跨境券商被整治、教育金规划迷茫、理财产品暴雷等）

**底层逻辑：** 恐惧是最强的行动催化剂，但单纯的恐惧只会让人僵住——必须同步给出"出路"，让客户看到希望。

**话术模板：**

```
先说结论："你的钱不会丢，但你的路会变窄。"
↓
说清楚发生了什么（不是客户的问题，是平台的问题）
↓
给出过渡期窗口（紧迫感）
↓
呈现替代方案对比表（维度：合规性/操作门槛/收益逻辑/通道风险/适合人群）
↓
锁定最适合的那条路
```

**关键句：**
- "先把事情弄清楚再行动。"
- "罚的是开店的人，不是吃饭的人。"（比喻）
- "监管关上的是非法通道，不是海外投资的大门。"

**禁忌：** 不要夸大恐惧，不要暗示"当初听我的就好了"——这会引发防御心理。

---

## 框架二：竞品对比（表格降维）

**触发情境：** 客户在两个产品之间犹豫，或对竞品有不切实际的理解

**底层逻辑：** 对比表的目的是让客户自己得出结论——不是你说竞品不好，而是让对比维度替你说话。

**标准维度（可按产品调整）：**
| 维度 | 竞品A | 我方产品 |
|------|-------|---------|
| 合规性 | ❌ | ✅ |
| 操作门槛 | 高（需主动交易） | 低（持有即可） |
| 收益逻辑 | 取决于选股能力 | 长期稳健复利 |
| 通道风险 | ⚠️ 政策风险 | 无此风险 |
| 适合人群 | 有交易能力的人 | 所有人 |

**关键句：**
- "你不是交易员，你也不需要成为交易员。"
- "大部分人的核心需求不是炒股赚钱，而是把一部分钱放到一个安全、合规、长期增值的美元资产里。"

---

## 框架三：身份锚点（降低行动门槛）

**触发情境：** 客户觉得"产品很好但不适合我"或"我现在不需要"

**底层逻辑：** 把产品跟客户的真实身份角色绑定，让客户觉得"这是我作为XX应该做的"。

**核心句式：**
```
"你是两个孩子的妈妈，孩子的教育金不能靠运气。"
"你现在是给孩子做教育金储备最好的时候——不是因为贵，是因为早。"
"十一年前投保和现在投保，保障时间差十年，那十年的复利是你的。"
```

**适用角色：**
- 妈妈 → 孩子教育金/传承
- 家庭经济支柱 → 底线保障
- 投资者 → 资产配置中的"兜底账户"

---

## 框架四：去阻抗（不否定客户）

**触发情境：** 客户说"我觉得现在不是时候"或"我觉得炒股更划算"

**底层逻辑：** 从来不要直接否定客户。承认客户的感受和判断有道理，然后从另一个角度切入。

**话术序列：**
1. 承认："你做投资判断一定有你的道理。"
2. 提问引导："你现在的投资收益，是账面子还是已经落袋的？"
3. 区分："投资账户和保障账户，解决的是不同的问题。"
4. 重建："你可以同时拥有——一个是进攻，一个是兜底。"

**关键转折句：**
- "不需要从股市取钱，从每月收入分一小部分即可。"
- "保单是一个独立账户，不碰你现在的股市资金。"

## 框架五：长期复利叙事（愿景牵引）

**触发情境：** 客户关注短期收益，对"长期"没有概念

**底层逻辑：** 把时间变成客户的朋友，而不是敌人。用数字让复利可见。

**核心叙事：**
```
"如果从孩子1岁开始投保，到孩子18岁去上大学，
  这17年，你不是在消费这份保单，
  你是在和時間一起，为孩子建立一个和股市无关的教育金账户。"

"时间是你的盟友，不是敌人。
  17岁的复利和27岁的复利，差的是整整十年的积累。"
```

**数字锚点（香港储蓄险参考）：**
- 5年缴，第15年约IRR 3.5-4%
- 第20年约IRR 5-5.5%
- 美元计价 → 天然对冲汇率波动

## 框架六：紧迫感制造（真实而非恐吓）

**触发情境：** 客户说"我再想想"

**底层逻辑：** 真正的紧迫感来自真实的时间窗口，不是制造的焦虑。

**真实紧迫感来源：**
- 投保年龄：每大一岁，同样保费，保障时间少一年
- 等待成本：早投保一年，早一年复利积累
- 孩子教育金：18岁大学是硬性时间节点，不能等

**关键句：**
- "教育金是18岁一定要用的钱，不能等它自己长出来。"
- "11岁投保不晚，但再等两年，就真的晚了两年。"

## 快速查用表

| 客户说 | 启动框架 | 核心动作 |
|--------|---------|---------|
| "股市更赚钱" | 去阻抗 + 身份锚点 | 区分进攻账户 vs 兜底账户 |
| "我觉得再等等" | 紧迫感 + 长期复利 | 锚定孩子年龄，算时间成本 |
| "不知道选哪个产品" | 竞品对比 | 表格对比，维度客户定 |
| "我朋友说不好" | 事件营销 + 去阻抗 | 问清楚"哪里不好"，针对性回答 |
| "我没钱" | 身份锚点 | 从每月收入拆分，不从股市取钱 |
| "政策风险太高" | 事件营销 | 合规渠道背书，监管关的是非法通道 |

## 使用方法

### 沟通前准备（1分钟）
1. 判断当前情境 → 选1-2个主框架
2. 准备1句"钩子话术"（开场第一句）
3. 准备1个"故事"（用过的客户案例或孩子教育金故事）

### 沟通中调用
直接说"客户说……，用框架三"，我帮你生成对应话术。

### 沟通后记录
- 用了哪个框架
- 客户当场反应如何
- 是否有新的客户语言需要加入
