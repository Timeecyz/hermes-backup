## 核心理念

**费曼学习法 × 2W2H 模型 × 主动回忆测试**

学习的本质不是「听过」，而是「能讲清楚」。用输出倒逼输入，用考核验证真正的理解。

---

## 三种考核模式

### 1. 读后费曼（最常用）
学完任何保险内容后，用 2W2H 讲给生活大管家听：

| 维度 | 问题 |
|------|------|
| W1 | 这个概念/产品是什么？（一句话说清楚） |
| W2 | 为什么重要？解决了什么问题？ |
| H1 | 它是怎么运作的？ |
| H2 | 我怎么用它？（跟客户讲/处理异议） |

**评分标准：**
- L1：能说清楚，但用的术语客户听不懂 → 重讲
- L2：能举生活类比，客户能听懂 → 及格
- L3：能联系客户场景，带具体案例 → 扎实
- L4/L5：能回答追问，能在辩论中不输 → 精通

### 2. 随机抽考（每周1次）
- 时间：每周一早上9点（cron自动触发）
- 内容：从知识库薄弱区抽取
- 格式：概念题 + 客户场景题
- 反馈：我给打分，指出盲区，推荐下一步

### 3. 案例复盘（每次销售后）
- 客户问了什么
- 我怎么答的
- 大管家评估：是否抓住本质，改进建议

## 蛮子保险知识库各知识点 L1-L5 要求

### 储蓄分红险（L3要求）
- W1：美元计价环球基金资产，一句话说清
- W2：解决什么问题——美元资产配置+高预期收益+全球分散风险
- H1：固定收益（合同写明）+ 浮动分红（看投资成绩，每年报分红实现率）；资金锁定期/回本周期
- H2：什么人适合（家庭结构+财务目标）；和内地储蓄险的核心差异（美元 vs 人民币，保证 vs 预期）
- 盲区：必须会讲「分红不确定」和「分红实现率查询方式」

### 重疾险 L3 要求（下一题）
- W1：香港重疾险是什么
- W2：为什么有人专门去香港买重疾险
- H1：疾病定义/赔付方式/费率结构差异
- H2：什么人适合买香港重疾险；什么人该买内地
