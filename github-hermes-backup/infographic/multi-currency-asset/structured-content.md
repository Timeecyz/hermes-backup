# Structured Content - 聪明人的资产，不押货币单选题

## Title
聪明人的资产，不押货币单选题

## Learning Objectives
1. 人民币国际化加速，跨境收付已达35万亿元，80+国家纳入外储
2. 单一货币押注风险大，真正高净值人群做综合配置
3. 综合配置核心是安全感而非收益
4. 港险是实现多货币配置的理想工具

## Content Sections

### Section 1: 核心数据 (Key Data)
- **35万亿元**: 2025年跨境人民币收付规模，同比增长14%
- **80+国家**: 将人民币纳入外汇储备
- **全球第三大支付货币** + **中国第一大结算货币**

### Section 2: 单一配置的风险 (Risk of Single Currency)
- 芒格：「不要把所有的牌押在一个地方。」
- 大多数人资产严重偏科：要么全押人民币理财，要么全换成美元存款
- 单一货币、单一市场、单一资产类别 → 任一货币出事，全部资产受影响

### Section 3: 综合配置方案 (Diversified Strategy)
- 美元 + 港币 + 人民币：三条腿走路
- 不同货币互相制衡、对冲风险

### Section 4: 港险的核心优势 (HK Insurance Advantages)
- 美元保单：分散单一人民币风险
- 港币保单：亚洲金融中心的底层资产
- 多币种转换功能：根据市场变化灵活调整
- 香港市场成熟、产品设计灵活、法律体系清晰

### Section 5: 核心结论 (Core Message)
- 综合配置的核心，从来不是「哪个货币涨得多」，而是「不管哪个涨，你都不亏」
- 真正聪明的资产配置：无论哪个货币涨，你都有
