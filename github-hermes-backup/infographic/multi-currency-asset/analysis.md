## Main Topic
关于全球货币多元化配置的理财理念，强调高净值人群通过美元、港币、人民币三条腿走路的综合配置策略来对冲风险，港险作为核心配置工具的优势。

## Learning Objectives
After viewing this infographic, the viewer should understand:
1. 人民币国际化加速，跨境收付已达35万亿元，80+国家纳入外储
